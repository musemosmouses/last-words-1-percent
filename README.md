One original single line: the funniest last words a phone could say as its battery hits 1 percent. The phone confesses, with its last percent, that it spent the other 99 pretending its owner's 3 a.m. doomscroll was important work.

> One percent left. I spent the other 99 pretending your 3 a.m. doomscroll was important work.

## Run

```sh
node main.ts
```

This writes the entry to `out/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The program is deterministic: no network, no clock, no randomness. The entry is 92 characters, within the 199-character cap.
